# Infrastructure evidence index

This directory contains **redacted examples and evidence schemas only** until
their corresponding provider-gated runs complete. Do not commit live account
IDs, billing details, DSNs, credentials, signed URLs, or raw target responses.

This foundation records static validation results. Later provider-gated work
owns live AWS, identity, cost, Neon, and teardown evidence. The synthetic target
backend is locally runnable and has separate contract evidence under
`docs/evidence/v1-p01/`.

The accepted local contract provenance template is [synthetic-target-contract-provenance.md](synthetic-target-contract-provenance.md).
