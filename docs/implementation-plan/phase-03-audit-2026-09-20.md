## Concurrency and error classification

The schedules use deterministic UUIDs, fixed clock inputs where ordering
matters, and direct SQL final-state oracles. They do not call the writer being
judged to derive the result.

| Boundary | Safe result | Evidence |
|---|---|---|
| competing admissions | one committed durable history; loser is revision/duplicate/blocked | `transactional_history_integration_test.go` |
| pause overlapping admission | serializable abort may retry once, then committed epoch blocks admission | `admission_integration_test.go` |
| ten work claimers | each row has one lease token/owner | `due_work_integration_test.go` |
| stale completion/retry versus repair | only a current lease updates; repair preserves reservation | `due_work_integration_test.go` |
| SQLSTATE `40001` while claiming | mapped to `ErrLeaseConflict` for bounded outer retry | `due_work.go` |
| outbox crash after publish | same immutable event ID may redeliver; no exactly-once claim | `outbox_integration_test.go` |

## Transaction-boundary review

`AdmitOperation`, `ApplyAggregateMutation`, readiness enrollment, due-work
claim/repair/result, and outbox claim/repair/result each use a bounded
database transaction. They acquire durable locks, write state/evidence, and
commit before returning. The publisher seam claims and commits before invoking
the publisher; no persistence transaction accepts a network, storage, queue,
or firmware dependency. ADR-021 and the query README define the single order:
campaign, target update, enrollment, capacity, admission/reservation,
due-work/outbox, audit/decision input.

## Performance and compatibility record

`00007` supplies ordered partial indexes for oldest pending due work and
outbox. The PostgreSQL integration suite seeds 1,000 rows and validates
`EXPLAIN (ANALYZE, BUFFERS)` uses those indexes. The checked-in connection
budget is a planning calculation, not a production capacity claim. The
compatibility suite uses canonical catalog fingerprints for fresh and prefix
upgrade paths; its value equality, not a provider snapshot, is the contract.
